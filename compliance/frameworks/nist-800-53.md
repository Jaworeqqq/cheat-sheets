# NIST SP 800-53

## TL;DR
NIST SP 800-53 (Rev. 5) is a comprehensive catalog of security and privacy controls — the backbone of US federal compliance (FISMA, FedRAMP) and widely used as a reference elsewhere. Controls are grouped into 20 families; baselines (Low/Moderate/High) select which apply based on system impact.

## Control families (20)
```text
AC Access Control          AU Audit & Accountability    AT Awareness & Training
CM Configuration Mgmt      CP Contingency Planning       IA Identification & Auth
IR Incident Response       MA Maintenance                MP Media Protection
PS Personnel Security      PE Physical & Environmental   PL Planning
PM Program Management      RA Risk Assessment            CA Assessment & Authorization
SC System & Comms Protection  SI System & Info Integrity  SA System & Services Acquisition
SR Supply Chain Risk Mgmt  PT PII Processing & Transparency
```

## Baselines (control selection)
```text
Categorize the system impact (FIPS 199): Low / Moderate / High (per C-I-A).
-> Select the matching baseline from SP 800-53B (which controls + enhancements apply).
-> Tailor: add/remove controls with justification (overlays for specific contexts).
```

## Where it's used
```text
- FISMA – mandatory for US federal information systems (via the RMF, SP 800-37).
- FedRAMP – cloud services to the US government (Low/Moderate/High baselines).
- Reference framework – many orgs map to 800-53 even without a federal mandate.
- Crosswalks to ISO 27001, CSF, CIS Controls (implement once, map to many).
```

## Risk Management Framework (RMF) context
```text
Categorize -> Select (baseline) -> Implement -> Assess -> Authorize (ATO) -> Monitor.
800-53 = the "Select/Implement" control catalog within RMF (SP 800-37).
```

## Practical notes
```text
- It's large (1000+ controls/enhancements) — baselines + tailoring keep it manageable.
- SP 800-53A gives assessment procedures (how to test each control) — see audit/control-testing.
- OSCAL (machine-readable format) enables automated compliance tooling.
```
