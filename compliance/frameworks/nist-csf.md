# NIST Cybersecurity Framework 2.0

## TL;DR
A voluntary, flexible framework for managing cyber risk. Version 2.0 (2024) added the **GOVERN** function and broadened scope beyond critical infrastructure to all organizations.

## 6 functions (Core)
```text
GOVERN (GV)   – strategy, roles/responsibilities, policies, risk management, supply chain oversight
IDENTIFY (ID) – assets, risks, business context
PROTECT (PR)  – access control, awareness, data security, configuration, hardening
DETECT (DE)   – continuous monitoring, event analysis
RESPOND (RS)  – incident management, analysis, communication, mitigation
RECOVER (RC)  – recovery plan, restoration, communication
```

## Elements
```text
Core        – functions > categories > subcategories (concrete outcomes)
Profiles    – Current vs Target (gap analysis -> plan)
Tiers (1-4) – maturity: Partial -> Risk Informed -> Repeatable -> Adaptive
```

## How to use it
```text
1. Set a Target Profile (where we want to be, per business risk).
2. Assess the Current Profile (where we are).
3. Gap analysis -> prioritized action plan.
4. Measure progress, iterate.
```
